# Daily Log

日志记录桌面程序的基础项目，使用 Tauri 2、React 和 TypeScript。
支持自定义多个关注项（例如睡眠、饮食），每日分别填写完成情况和备注，并在概览中按月或按年查看。

导航分为“今日”“概览”“管理”；“管理”包含“打卡”和“事件”；独立的“设置”入口以弹窗提供外观和数据存储设置。

## 记录规则与存储

- 在“管理 → 打卡”添加名称；移除采用归档方式，历史保留，随时可以恢复。
- 每个关注项单独配置任意数量的状态（至少一个）；支持添加、删除、改名、上下排序。
- 可选择“由差到好”或“由好到差”，切换方向会反转列表并保持颜色含义。
- 颜色按等级自动从红经黄到绿过渡；单状态采用中间色。每日记录选取其中一个状态，并可附上最多 2000 字备注。
- 创建默认提供“极差 / 差 / 一般 / 好 / 非常好”五档，可自由修改。已有项可在“管理 → 打卡”点击“编辑状态”。
- 每条记录保存当时的状态名称与相对等级，之后修改配置不改变历史文字和颜色；当天再次保存才更新。
- 每项独立保存，当天可修改；可在“概览”中定位过去日期并修改或补记。以电脑本地日期为准。
- “概览”支持月度 / 年度切换。长期关注保留每日格子；事件按起止日期展示连续时间条，按当天状态着色；均可切换时间、筛选内容、点击日期查看详情。事件时间条可用左右方向键逐日选择，跨月/跨年及无结束日期用箭头表示继续。
- 概览的每日记录格只显示颜色，不显示状态文字或占位符；悬停可看状态，点击可查看和编辑详情。空白表示“未记录”，不计为最差等级；当前时间范围的汇总显示记录数、涉及关注项数和有记录的天数，每项下方显示当前状态图例。
- 已归档的关注项在存在记录的月份仍显示，也可以通过筛选查找。
- 关注项与记录统一保存在 `state.json`（数据格式版本 6），每次保存先写临时文件，再原子替换，失败不会先清空旧文件。
- 版本 2 自动迁移为独立状态配置，迁移前备份为 `state-v2.backup.json`。
- 旧版每日 JSON 自动迁移到“原每日打卡”归档项，原始文件保留；仅在没有 `state.json` 时执行迁移。
- 保存位置为系统应用数据目录内的 `com.yajiey.dailylog/check-ins`；Mac 上通常是
  `~/Library/Application Support/com.yajiey.dailylog/check-ins`。侧栏显示实际路径，并可打开文件夹。
- 关闭和重新打开应用后自动读取原有文件。可复制整个文件夹备份；损坏文件显示错误，不会被自动覆盖。
- 可选择 iCloud Drive 等系统同步文件夹。文件的云端上传、下载由系统负责，应用不报告云端同步完成；请避免多设备同时编辑。

## 打卡重复规则

- “管理 → 打卡”新增和编辑时可设置 Repeat：每天、每周指定星期、每月指定日期、固定日期仅一次。
- “今日”只显示当天计划中的打卡项；当天已有记录的项目即使调整规则，也继续保留显示。
- 每月没有所选日期时跳过，不会把 31 日自动挪到月末。固定日期只在该日出现，不会每日重置。
- 概览将计划外日期显示为“无需打卡”；每周、每月重复项可先额外添加该日，再补记。已有记录仍可修改。
- “今日”和概览日期详情可“跳过这一天”并恢复；跳过显示为斜纹，不计入记录汇总，原有记录和备注保留。
- “今日”的“额外添加一次”可选择日期和每周／每月打卡项，用于调休等单日例外；支持提前安排未来日期，到当天才能填写。未填写前可取消本次添加。
- 单日例外不会修改重复规则；版本 5 自动迁移并保存 `state-v5.backup.json`，历史记录与重复规则保持不变。
- 修改规则从当天生效，规则历史按日期保留；过去日期的补记依照当时的计划判断。
- 版本 4 迁移前保存 `state-v4.backup.json`，现有项目默认保持每天，历史记录和状态配置不变。

## 事件

- “管理 → 事件”用于旅行、短期计划等阶段性事项，可设置名称、简介、起始日期和可选结束日期，复用独立状态配置。
- 起始日、计划结束日均可记录；结束日次日起自动停止出现在每日记录中。没有结束日期则持续记录，概览中的时间条只延伸到今天，不预铺未来日期；日期切换后自动增长。
- 事件开始后可手动结束，保留当天的记录入口及全部历史，次日起停止记录；结束操作需在界面确认。
- 计划结束当天和到期后均可延期，新结束日期必须晚于原结束日期且不早于今天。手动结束后不再提供延期。
- 每日记录按“长期关注 / 今日事件”展示。概览可筛选全部内容、长期关注或事件，月度和年度均支持。
- “今日”只记录当天；“概览”可修改或补记过去日期，事件仍受起止日期限制，未来日期和创建日前均不能填写。
- 编辑历史备注时可以保留原状态的名称与颜色，即使该状态已经改名或移除。历史保存会校验记录版本，避免覆盖编辑期间已发生的其他修改。
- 版本 3 迁移前自动保存 `state-v3.backup.json`，保留原关注项、状态配置和历史记录；原有版本 2 迁移仍受支持。

## 设置与主题

- 点击侧栏“设置”打开弹窗，可在“外观”和“数据存储”之间切换；Escape、完成或关闭按钮可关闭，焦点返回原入口。
- 主题色提供森林绿、海湾蓝、暮光紫、暖陶橙、玫瑰粉和自定义颜色，背景可独立选择柔和底色或纯白；立即应用并保存在当前设备，重启后沿用。外观不会改变历史打卡状态的红绿等级含义。
- 选择文件夹或迁移过程中禁止关闭设置，避免中断切换。数据迁移成功后弹窗保持打开，显示最新存储位置。

## 数据存储与 iCloud Drive

- 进入“设置 → 数据存储”，选择空的专用文件夹（例如 iCloud Drive/日日记），预览后确认迁移。迁移采用复制、校验、最后保存配置的顺序，原目录保留。
- 若所选目录已有有效的 `state.json`，先显示项目数和记录数，确认后打开该数据集；不会与原目录自动合并或覆盖目标已有文件。取消选择不会切换目录。
- 可“恢复默认位置”；若默认目录仍有旧数据，会明确提示打开那份旧数据，原自选目录保留。
- 存储配置在本机应用数据根目录的 `storage-settings.json`，不随云目录同步。正式数据仍为版本 6 的 `state.json`。
- 每次保存前和切换前，旧数据备份到本机 `storage-backups`；目标已有数据也会先备份。可从界面打开该目录；备份不会自动清理，可定期手动整理。
- 保存时使用文件版本指纹与本机文件锁检测已到达本机的外部变化；冲突时拒绝覆盖并将本次修改副本保存在本机备份。自动检查发现变化会保留当前表单，提示先复制未保存内容再手动刷新。
- 这不是跨设备事务或自动合并：两台离线设备的修改可能稍后发生系统同步冲突，应用不会自动识别、合并所有 iCloud 冲突版本。避免同时编辑，切换设备前请等待系统同步完成。
- 自选目录不可用或文件未下载时，停止读写，不会创建空记录或静默回退。可等待文件下载后刷新，也可在“数据存储”中选择已有数据恢复；源目录不可用时会提示无法备份最新源内容，禁止向空目录迁移。
- 模拟日期继续使用本机独立的 `debug-check-ins`，首次从当前正式目录复制；模拟模式禁止切换正式目录。

## 日期调试

- 点击侧栏底部“日期调试”展开面板，查看系统日期、应用当前日期、检查次数、检查来源和日期变化日志。
- 面板打开时每 5 秒检查；平时每 60 秒检查，窗口聚焦及本地午夜也会触发检查。
- 可以选择任意模拟日期，或使用“前一天 / 后一天”，观察事件开始、到期、延期、结束与每日记录切换。
- 模拟日期由 Rust 后端统一用于写入校验，模拟记录会存到 `debug-check-ins`。首次进入复制真实数据；后续沿用测试副本，正式 `check-ins` 不受模拟写入影响。
- 切换模式或日期会清空当前界面的未保存表单，测试前先保存真实记录；状态日志只在本次运行保留，最多 50 条。
- 点击“恢复系统日期”返回真实数据；重启应用也会自动恢复。模拟数据保留供下次调试，保存时间仍为真实系统时间。

## 本机启动（macOS）

```sh
cd /Users/yajiey/Desktop/general/daily-log
source "$HOME/.cargo/env"
DEVELOPER_DIR=/Library/Developer/CommandLineTools npm run tauri dev
```

本机已安装 Command Line Tools。上述命令仅为当前进程选择这套工具，
避免当前完整 Xcode 尚未确认许可导致的编译错误。

## 检查与构建

```sh
npm run build
DEVELOPER_DIR=/Library/Developer/CommandLineTools cargo test --manifest-path src-tauri/Cargo.toml
DEVELOPER_DIR=/Library/Developer/CommandLineTools npm run tauri build
```

## 其他电脑

先按 [Tauri 官方说明](https://v2.tauri.app/start/prerequisites/) 安装目标系统的编译依赖、
Rust stable 和 Node.js，然后运行 `npm ci` 与 `npm run tauri dev`。
Windows 和 Linux 需要在各自系统上单独构建、测试。

`package-lock.json` 和 `src-tauri/Cargo.lock` 用于锁定依赖版本。
