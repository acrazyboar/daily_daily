日日记首个可下载测试版，适用于 **Apple Silicon（M1/M2/M3/M4 等）Mac，macOS 13 或更高版本**。本次不包含 Intel Mac、Windows 或 Linux 安装包。

## 下载与安装

- `.dmg`：下载后打开，将应用拖到“应用程序”文件夹。
- `.zip`：解压得到“日日记.app”，移动到“应用程序”文件夹。
- `SHA256SUMS.txt`：用于核对下载文件的 SHA-256 校验值。

这是未经过 Apple Developer ID 签名和 Apple 公证的预发布测试版（仅作 ad-hoc 签名）。首次打开可能被 macOS 安全机制阻止。请核对来源后，按 macOS“系统设置 → 隐私与安全性”的提示允许打开。此版本不是 App Store 正式发行版。

更新前请退出旧版日日记，并备份数据文件夹。安装包不包含开发者的个人记录；替换应用不会主动删除原有数据。本版尚未提供自动更新，后续可从 Releases 下载新版覆盖安装。

## 包含的功能

- 自定义打卡项、状态等级和重复规则，支持单日跳过和计划外额外添加。
- 事件起止日期、每日状态记录、结束和延期。
- 月度和年度概览，记录格仅显示颜色，支持查看和修改历史记录。
- 设置弹窗，提供主题色、白色主题、独立纯白背景和数据存储设置。
- 可选择 iCloud Drive 等文件夹，迁移前备份；云端上传、下载由操作系统负责。
- 左上角“日”图标一秒内连续点击三次打开或收起日期调试；模拟记录使用独立目录。

## 已知限制

- iCloud Drive 文件同步不等同于多设备自动合并，请避免多台设备同时编辑；本版无法自动处理所有离线同步冲突。
- 默认数据位置：`~/Library/Application Support/com.yajiey.dailylog/check-ins`；若更改过位置，以应用设置显示的目录为准。
- 本次仅提供 Apple Silicon 构建，不承诺 Intel Mac 兼容性。

遇到问题请在本仓库 Issues 反馈，附上系统版本与重现步骤；请勿上传含个人日志的完整数据文件。
